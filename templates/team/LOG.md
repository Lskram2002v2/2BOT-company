# สมุดบันทึกร่วมของบอท — เขียนต่อท้ายเท่านั้น ห้ามแก้/ลบของเก่า (ยกเว้นติ๊กช่อง "รับทราบ" ของตัวเอง)

ก่อนเริ่มงานใหม่ทุกครั้ง: อ่านบันทึกตั้งแต่ครั้งล่าสุดที่ตัวเองอ่าน + อ่าน CLAUDE.md ใหม่ (session ที่เปิดค้างไม่เห็น CLAUDE.md ฉบับแก้)
มีบรรทัด `รับทราบ: <ตัวเอง> ☐` ค้าง = อ่านกฎที่เปลี่ยนให้จบ แล้วแก้เป็น `☑ <เวลา>` ก่อนทำงานอื่น
จบทุกงาน (หรือโดนหยุด/โควตาหมด) เขียน 1 รายการตามแบบนี้:

```
## YYYY-MM-DD HH:MM · bot1|bot2 · <งานสั้นๆ>
- ทำ: …
- ผล: … (branch / commit / ไฟล์ / ลิงก์)
- ผู้ใช้ว่า: … (อนุมัติ / ให้แก้ / ยังไม่ตรวจ)
- เรียนรู้: … (ข้อผิดพลาด → สาเหตุ → วิธีกัน)
- นโยบาย: ไม่เปลี่ยน | เปลี่ยน <ไฟล์>: <อะไร> เพราะ <ผู้ใช้สั่ง/บทเรียน> (commit <hash>)
- รับทราบ: botX ☐   ← ใส่เฉพาะเมื่อนโยบายเปลี่ยน
- ค้าง/ต่อ: …
```
คำนำหน้าชื่องาน: `ทดลอง:` = ยังไม่ใช่นโยบายจนกว่าผู้ใช้อนุมัติ · `ตรวจ:` = รีวิวงานของอีกบอท · `CF:` = ปิดฟีเจอร์ + สรุปบทเรียน
